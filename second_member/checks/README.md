# Дополнительные проверки методов (отдельно от рабочего кода)

Скрипты независимой проверки, сделанные 25.10.2026. Это не часть основного расчёта: они проверяют,
можно ли доверять методам, и из них взяты числа суррогатной проверки в отчёте.
Пути к коду и к CSV считаются от расположения скрипта. Кеш данных (`d.pkl`) пишется в текущую папку
скриптом `acf_review/load.py`, кеш участков (`segs.pkl`) — рядом с `bootstrap_review/common.py`;
перед повтором их нужно создать заново.

- `acf_review/` — этап 4: сверка ACF statsmodels с ручным счётом; занижение tau_c в коротких окнах
  (окна rep0 по 144 кадра: ACF(1)=0.37 при центрировании по окну, 0.63 — по всей фазе); синтетика AR(1)+шум.
- `bootstrap_review/` — этапы 5–6: совместный ресэмплинг n и cn в arch; смещение бутстрэпа tau_c
  (склейки блоков, плоская ACF у 1/e); суррогаты с тем же спектром — блочная перестановка отвергает
  верную H0 в 43–71% случаев (номинал 5%), SE среднего занижена в ~1.6–1.8 раза; при суррогатной SE
  разность средних n (−0.76, z=−2.6) и TVD (0.285; ни один из 300 суррогатов не ≥0.285) выдерживают,
  разность средних cn (−0.44, z=−1.9) — пограничная.
