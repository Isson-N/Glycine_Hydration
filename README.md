# Гидратация глицина и корреляционное время водного окружения в GlyT1

Курсовая работа по дисциплине «Теоретические основы кибернетики» (тема 2).
Выполнили студенты группы 3.4.31 Бессонов Илья и Смуток Денис, 2026.

Вопрос: различаются ли распределение числа молекул воды вокруг глицина и время его автокорреляции
в сайте связывания и в области около 8 Å от него? Основная траектория — rep2, контрольная — rep0.

## Как повторить расчёт

Исходный файл `gly_matrix_all_reps.csv` в репозиторий не входит; положите его в `data/`.
Нужен Python 3 с пакетами numpy, pandas, scipy, statsmodels, arch, matplotlib, openpyxl.
Команды выполняются из корня репозитория:

```bash
python second_member/run_member1_C.py        # этапы 1–3
python second_member/autocorrelation.py C    # этап 4
python second_member/bootstrap.py C          # этапы 5–6 (~2 мин)
python second_member/autocorrelation.py C2   # проверка на втором окне плато
python second_member/bootstrap.py C2
python second_member/extras.py               # этап 7
python second_member/regions_final.py        # рисунок выбранных участков
```

Вместо `C` можно указать `A` или `B`, чтобы получить результаты для других вариантов участков.
Бутстрэп использует фиксированное начальное значение генератора (seed = 1), поэтому числа повторяются.
